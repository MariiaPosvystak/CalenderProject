## 📋 Sisu ülevaade
 
### 📆 Kalender (index.html)
 
Juhend selgitab 6 sammuga, kuidas:
 
1. Avada **Change Working Time** aken (`Project` → `Change Working Time`)
2. Tutvuda olemasoleva standardkalendriga
3. Luua uus baasikalender nupuga **Create New Calendar…**
4. Lisada erand koos kordumismustriga sakil **Exceptions** (nt tööajad 14:00–18:00 ja 19:00–23:00)
5. Rakendada uus kalender ülesandele läbi **Task Information → Advanced → Calendar**
6. Vaadata tulemust — ülesannete algus- ja lõpuaeg muutuvad vastavalt uuele kalendrile
### 📊 Diagrammid (diagramm.html)
 
Juhend selgitab 4 sammuga, kuidas:
 
1. Kasutada **Gantt Chart** vaadet — ribade ja värvide tähendus (sinine ülesanne, punane kriitiline tee, must romb verstapost)
2. Kasutada **Network Diagram** vaadet ülesannete seoste ja kriitilise tee analüüsimiseks
3. Eksportida Gantt Chart PDF-iks, Exceli failiks või kopeerida lõikelaua kaudu Word/PowerPointi
4. Vaadata videoõpetust diagrammivaadete kasutamise kohta

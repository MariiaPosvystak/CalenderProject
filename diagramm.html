Microsoft Project'is

01

Gantt Chart vaate kasutamine

Gantt Chart on vaikimisi vaade Microsoft Project'is. Vasakul on ülesannete tabel, paremal ribdiagramm. Ribad kujutavad ülesande kestust, nooljooned sõltuvusi.

Gantt riba värvide tähendus: sinine – tavaülesanne, punane – kriitiline tee, must romb – verstaposts.

Kuidas avada: View → Gantt Chart või Tracking Gantt (näitab planeeritud vs tegelik).
02

Kriitiline tee – Critical Path

Kriitiline tee on ülesannete jada, mis määrab projekti minimaalse lõpukuupäeva. Iga viivitus kriitilisel teel lükkab projekti lõppu edasi.

Kriitilise tee aktiveerimiseks mine Format → luba Critical Tasks. Kriitilised ülesanded muutuvad punaseks.

💡 Jälgi alati, kas sinu projekt on ajas. Kui kriitiline tee venib, tea, et projekt hilineb täpselt sama palju.
03

Network Diagram (võrgudiagramm)

Mine View → Network Diagram. Iga ülesanne kuvatakse kastina, sõltuvused nooltena. See vaade on hea kriitilise tee ja ülesannete seoste analüüsimiseks.

Kastid näitavad ülesande nime, kestust, algus- ja lõpuaega. Kriitilised kastid on tavaliselt punase raamiga.

Nõuanne: Võrgudiagramm muutub suurtel projektidel raskesti loetavaks. Kasuta seda eelkõige sõltuvuste kontrollimiseks.
04

Resource Graph (ressursigraafik)

Mine View → Resource Graph. Graafik näitab ressursi (inimese) töökoormust ajaliinil. Punased tulbad tähendavad ülekoormust (rohkem kui 100% tööd).

Ülekoormuse lahendamiseks saad kasutada Resource Leveling funktsiooni – see jaotab töö ümber automaatselt.

✅ Enne projekti esinemist kontrolli alati ressursigraafikut – ülekoormatud ressurss on üks peamisi viivituste põhjusi.
05

Diagrammi eksportimine ja jagamine

Gantt Chart'i saab eksportida mitmel viisil:

• File → Print → vali printer Microsoft Print to PDF
• File → Export → Save Project as File → Excel Workbook
• Kopeeri Gantt graafik lõikelaua kaudu Word/PowerPoint dokumenti

Nõuanne: Enne printimist kasuta File → Print Preview, et kontrollida, kas kogu ajakava mahub lehele.
